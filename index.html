Date : 04/11/2026

Convention : Les éléments affichés en bleu sont des variables dont le nom peut être personnalisé.

Thread

Ajouter une fonction dans un Thread

Permet de créer un Thread qui exécutera une fonction.

Thread myThread = new Thread(FONCTION);

Démarrer le Thread

Pour lancer l'exécution du Thread :

myThread.Start();

Ouvrir une fenêtre pour sélectionner un fichier

Création de la fenêtre

OpenFileDialog openFileDialog = new OpenFileDialog();

Définir le répertoire de départ

Permet de définir le dossier dans lequel la fenêtre s'ouvrira.

openFileDialog.InitialDirectory = "C:\\MesDocuments\\Cantons";

Ou utiliser le dossier dans lequel se trouve le fichier EXE :

openFileDialog.InitialDirectory = Application.StartupPath;
Cette propriété définit le répertoire initial, mais n'ouvre pas elle-même la fenêtre de sélection.

Afficher la fenêtre et récupérer le fichier

La fenêtre s'ouvre. Si l'utilisateur clique sur OK, on récupère le chemin du fichier sélectionné.

if (openFileDialog.ShowDialog() == DialogResult.OK)
{
    // Récupère le nom complet du fichier sélectionné
    FileName = openFileDialog.FileName;
}

Ajouter un titre à la fenêtre

openFileDialog.Title = "Sélectionner le fichier";

Filtrer les extensions

Permet de choisir quels types de fichiers sont affichés.

openFileDialog.Filter =
    "Fichiers texte (*.txt)|*.txt|Tous les fichiers (*.*)|*.*";

DataGridView

Vider les colonnes du DataGridView

Supprime toutes les colonnes du tableau.

dgv.Columns.Clear();

Ajouter des colonnes

Permet de créer les colonnes du tableau.

Premier paramètre : le nom utilisé dans ton code.
Deuxième paramètre : le texte affiché dans l'en-tête du tableau. 
dgv.Columns.Add("Nom", "Nom du canton");

dgv.Columns.Add("Population", "Population suisse");

Ajouter des lignes

Permet d'ajouter une ligne avec les valeurs souhaitées.

dgv.Rows.Add("Genève", 520000);

Exemple de résultat

Nom du canton Population suisse
Genève 520000
