Thread Sélectionner un fichier DataGridView

Voici quelques notes et exemples de code que j'utilise en C#. Le but est de retrouver facilement certaines commandes et de comprendre rapidement leur utilisation.

Les éléments écrits en bleu sont des variables dont le nom peut être personnalisé.

Thread

Ajouter une fonction dans un Thread

Créer un Thread qui exécutera une fonction :

Thread myThread = new Thread(FONCTION);

Démarrer le Thread

myThread.Start();

Ouvrir une fenêtre pour sélectionner un fichier

Création de la fenêtre

OpenFileDialog openFileDialog = new OpenFileDialog();

Définir le répertoire de départ

Définit le dossier dans lequel la fenêtre doit s'ouvrir :

openFileDialog.InitialDirectory = "C:\\MesDocuments\\Cantons";

Ou utiliser directement le dossier contenant le fichier .EXE :

openFileDialog.InitialDirectory = Application.StartupPath;
Cette commande définit uniquement le répertoire de départ. Elle n'ouvre pas la fenêtre.

Afficher la fenêtre et récupérer le fichier

La fenêtre s'affiche. Si l'utilisateur clique sur OK, le chemin du fichier est récupéré :

if (openFileDialog.ShowDialog() == DialogResult.OK)
{
    // Récupère le nom complet du fichier sélectionné
    FileName = openFileDialog.FileName;
}

Ajouter un titre à la fenêtre

openFileDialog.Title = "Sélectionner le fichier";

Filtrer les extensions

Permet de limiter les fichiers affichés à certaines extensions :

openFileDialog.Filter =
    "Fichiers texte (*.txt)|*.txt|Tous les fichiers (*.*)|*.*";

DataGridView

Vider les colonnes

dgv.Columns.Clear();

Ajouter des colonnes

Ajoute une nouvelle colonne au DataGridView :

Premier paramètre : le nom utilisé dans le code.
Deuxième paramètre : le texte affiché dans l'en-tête du tableau. 
dgv.Columns.Add("Nom", "Nom du canton");

dgv.Columns.Add("Population", "Population suisse");

Ajouter des lignes

Ajoute une ligne avec les valeurs indiquées :

dgv.Rows.Add("Genève", 520000);

Résultat

Nom du canton Population suisse
Genève 520000
